# UrbanNest — Fully Working Frontend

A frontend-only real-estate website with working interactions and browser-local data storage.

## Included working actions
- Property search by type, location and budget
- Property category chips and reset filters
- Save/unsave properties
- Property details modal
- Mortgage/EMI calculator sliders
- Dark/light theme toggle
- Mobile navigation menu
- Contact/enquiry form saved to localStorage
- User registration/login/logout
- Demo admin login and admin property management
- Add, edit and delete properties
- Delete enquiries
- Escape-key and backdrop closing for dialogs

## Run
Open `index.html` in a modern browser after extracting the ZIP. For the most reliable browser behavior, serve the `UrbanNest` folder with any simple local web server.

All account, property and enquiry data is stored locally in the browser; there is no backend.
